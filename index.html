🎯 Casos de Uso Iniciales – Módulo 5: Business Analytics

1️⃣ Book de People Analytics automatizado

Propósito: Generar automáticamente el “People Book” mensual (32 págs.) con KPIs de plantilla, costes, rotación y absentismo.

Fuente: Oracle HCM / Payroll / BI corporativo

Impacto: –90 % tiempo · +100 % calidad de datos

2️⃣ Reconciliación HC–FTE Oracle ↔ BI

Propósito: Alinear cifras de plantilla entre sistemas y eliminar discrepancias.

Fuente: Oracle HCM / Data Lake BI

Impacto: Datos consistentes · Validación automática

3️⃣ Control de absentismo y alertas

Propósito: Detectar picos de ausencias por centro o turno con alertas automáticas.

Fuente: Oracle Attendance / RRHH local

Impacto: –60 % tiempo de reacción · Mejora operativa

4️⃣ Análisis de costes vs presupuesto

Propósito: Monitorizar desviaciones por fábrica, área o centro de coste.

Fuente: Oracle Payroll / Contabilidad

Impacto: Visión financiera integrada · Control preventivo

5️⃣ Seguimiento de rotación y estabilidad

Propósito: Visualizar índices de rotación y alertas de variaciones fuera de rango.

Fuente: Oracle HR_EXIT / BI histórico

Impacto: Detección proactiva · Decisiones ágiles

6️⃣ Formación y cumplimiento obligatorio

Propósito: Controlar cumplimiento de formación legal o de rol por unidad.

Fuente: LMS / Oracle HCM

Impacto: Visibilidad 100 % compliance · Ahorro manual

7️⃣ Data Quality Scorecard

Propósito: Crear un cuadro de control de calidad del dato HR (completitud, duplicados, validez).

Fuente: Oracle HR / Payroll

Impacto: +95 % fiabilidad global · Base sólida futura
